# CleanWeb — блокировщик рекламы для Android

Блокирует рекламу, трекеры, домены-редиректоры и вредоносные сайты во всех браузерах и приложениях. Root не нужен: приложение поднимает локальный VPN, через который проходят только DNS-запросы, и проверяет каждый домен на самом телефоне.

Реализован **этап MVP** из ТЗ (раздел 6). HTTPS-фильтрация (видеореклама, pop-up, косметика) — версия 1.1.

## Что готово (MVP)

| ТЗ | Что сделано |
| --- | --- |
| F-01 | Локальный `VpnService`: перехват DNS (IPv4 и IPv6), ответ `0.0.0.0` / `::` для заблокированных доменов |
| F-02 | Зашифрованный upstream DoH: Cloudflare, Quad9, AdGuard DNS, Google или свой (`https://…/dns-query` или IP). Запасной путь — обычный UDP |
| F-03 | Проверка «Частного DNS» с переходом в настройки (на главной и в онбординге) |
| F-07 | Режим «только DNS» — сейчас это единственный режим |
| 2.3 | Встроенные списки: AdGuard DNS filter, EasyList, EasyPrivacy, RU AdList, AdGuard Base, URLhaus. Свои списки по URL, «Мои правила», белый список. Обновление раз в сутки (WorkManager), опция «только Wi-Fi» |
| 2.3 | Синтаксис: hosts, списки доменов, доменные правила ABP/uBO/AdGuard (`\|\|domain^`, `@@`, `$third-party`, `$important`, `$document`, `$popup`). Правила с путями и косметика пропускаются — это уровень 1.1 |
| 2.4 | Экран «Приложения»: исключение любого приложения из фильтрации. Банки и «Дія» исключены по умолчанию |
| 2.5 | Журнал запросов (время, приложение на Android 10+, домен, статус), поиск и фильтр, блок/разрешение домена одним нажатием, автоочистка (1/3/7/30 дней). Хранится только на телефоне |
| 2.6 | Плитка Quick Settings, автозапуск после перезагрузки, поддержка «Постоянного VPN» |
| 4 | Онбординг из 3 шагов, главная с кнопкой Вкл/Выкл и счётчиками, уведомление со счётчиком и «Пауза на 5 минут», понятные сообщения об ошибках. Тема светлая/тёмная/системная, Material You |
| 1 | Интерфейс на русском, украинском и английском |

Замеры на компьютере: 5 списков по умолчанию дают ~216 000 уникальных правил, загрузка ~0,5 с, проверка домена ~0,5 мкс (по ТЗ — < 1 мс). Release-APK — 2,6 МБ (по ТЗ — ≤ 25 МБ).

## Что ещё не сделано

- **Версия 1.1:** HTTPS-фильтрация (MITM, сертификат), блок QUIC, полный синтаксис правил и косметика, видеореклама, страница-заглушка для редиректов.
- **Версия 1.2:** графики статистики, виджет, резервная копия настроек, «Сообщить о пропущенной рекламе».
- DNS-over-TLS (сейчас только DoH).
- Приложения с «зашитым» DNS (например, 8.8.8.8 напрямую) обходят фильтр — перехват таких запросов планируется вместе с полным туннелем в 1.1.
- **Приёмка на S24 Ultra не проводилась:** приложение собрано и покрыто unit-тестами, но на реальном телефоне ещё не запускалось. Батарея, стабильность 24 ч и банковские приложения проверяются по чек-листу из раздела 6 ТЗ.

## Сборка

Нужны JDK 17+ и Android SDK (platform 35).

```bash
./gradlew :app:assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:testDebugUnitTest    # unit-тесты фильтра и разбора пакетов
./gradlew :app:assembleRelease      # нужен свой ключ подписи
```

Проверка парсера на реальных списках:

```bash
./gradlew :app:testDebugUnitTest --tests '*parsesRealListsIfGiven*' -Plists=/path/a.txt,/path/b.txt -i
```

## Устройство кода

```
app/src/main/java/app/cleanweb/
  net/      разбор и сборка IPv4/IPv6 + UDP пакетов
  dns/      DNS: чтение вопроса, ответ-заглушка, TTL
  filter/   RuleSet (парсер правил) и FilterEngine (поиск по домену и родителям)
  vpn/      BlockerVpnService, UpstreamResolver (DoH + кеш), BlockerState
  data/     настройки, списки фильтров, журнал (SQLite), фоновое обновление
  system/   уведомления, плитка, автозапуск, проверки «Частного DNS» и батареи
  ui/       экраны на Jetpack Compose
```

Как идёт запрос: система отправляет DNS на адрес `10.111.222.1` (или `fd66:6c74:7765::1`), который ведёт в туннель → `FilterEngine` проверяет домен → заблокирован: ответ `0.0.0.0`; нет: запрос уходит в DoH, ответ кешируется по TTL. Само приложение исключено из VPN, поэтому его запросы не зацикливаются.
